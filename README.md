# ShutDown-Planner
A timer to shutdown your PC/laptop made with Python

The imports you need are: **tkinker** and **os**

Basically you can set a specific delay for your device to shut down.
This is useful if you download something overnight or during the day but you cannot be near your device to shut it down.

You can download the executable (.exe) from the **dist** folder. 
Or you can generate yourself a new one by running:
> pyinstaller --noconsole --onefile ShutDownPlanner.py

But you have to install first **pyinstaller** with the command:
> pip install pyinstaller
